# 🇯🇵 Japanese for Your Life

Платформа для изучения японского языка с интерактивным текстом, фуриганой и учебными режимами.

## 🚀 Быстрый старт

```bash
cd apps/japanese-reader
npm install
npm run dev
```

Откройте http://localhost:5173

## ✨ Возможности MVP
- **Интерактивный текст** с фуриганой (`<ruby>`/`<rt>`)
- **Подсветка частиц** (は, が выделены красным)
- **Русский перевод** с сопоставлением предложений
- **Озвучка** через Web Speech API
- **Автосохранение** текстов в IndexedDB
