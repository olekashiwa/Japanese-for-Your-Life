# 🇯🇵 Japanese for Your Life

Платформа для изучения японского языка с интерактивным текстом, фуриганой, словарём и учебными режимами.

## 🚀 Быстрый старт

```bash
cd apps/japanese-reader
npm install
npm run dev
```

Откройте http://localhost:5173

## ✨ Возможности MVP

- **Интерактивный текст** — отображение японского текста с фуриганой
- **Подсветка частиц** — частицы は, が и другие выделяются красным
- **Карточки слов** — клик по слову показывает чтение и часть речи
- **Разбиение на предложения** — автоматическая сегментация по 。！？
